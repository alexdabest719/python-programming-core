# python-programming-core
This repository tracks my progression through core Python programming concepts, culminating in a fully functional Object-Oriented application. It serves as the foundational backend architecture track before transitioning into Machine Learning and AI development.

## 🚀 Capstone Project: Dealership OS (`dealership_os_project.py`)
A command-line Dealership Management System built to demonstrate comprehensive Python backend architecture. 

**Architecture Highlights:**
* **OOP Design:** Utilizes class inheritance (`Vehicle` -> `Car`, `Truck`) and polymorphism.
* **Data Security:** Implements `@property` decorators for strict data validation (e.g., preventing negative vehicle prices).
* **Persistence:** Handles automated data parsing and file I/O exporting to CSV formats.
* **Testing:** Fully validated with an automated `pytest` suite (`test_project.py`).
